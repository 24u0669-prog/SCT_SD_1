# SCT_SD_1 — Temperature Converter

## SkillCraft Technology Software Development Internship — Task 01

### Task
Create a program that converts temperatures between Celsius, Fahrenheit, and Kelvin scales.

### Technology Used
- HTML
- CSS
- JavaScript

### Features
- Converts Celsius, Fahrenheit, and Kelvin.
- User can select source and target units.
- Validates empty/invalid input.
- Prevents temperatures below absolute zero.
- Responsive graphical user interface.

### How to Run
1. Open `index.html` in any modern web browser.
2. Enter a temperature.
3. Select the input unit.
4. Select the output unit.
5. Click **Convert**.

### Conversion Formulas
- Fahrenheit = (Celsius × 9/5) + 32
- Celsius = (Fahrenheit − 32) × 5/9
- Kelvin = Celsius + 273.15
- Celsius = Kelvin − 273.15
